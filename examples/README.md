# Examples

Professional, end-to-end workflows for the Power BI MCP Server. Each example lists its
objective, an example natural-language prompt, the **real** MCP tools involved, the expected
result and the professional use case.

> All write operations create an automatic backup first. Work on a copy of production
> projects, and keep Power BI Desktop closed while this server operates on the files.

| Example | What it shows |
|---------|---------------|

| [powerbi_project_analysis.md](powerbi_project_analysis.md) | Audit data quality, relationships and best practices |
| [dax_measure_workflow.md](dax_measure_workflow.md) | Draft, validate and add a DAX measure |
| [documentation_generation.md](documentation_generation.md) | Generate technical docs and a data dictionary |
